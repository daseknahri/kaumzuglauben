# KaumZuGlauben — "Unglaubliche Fakten, die wirklich stimmen."

German **shocking-facts** site: true stories and facts that read as invented —
history shocks, nature superpowers, body wonders, everyday myths fact-checked, and
world records with the stories behind them. Built for the owner's German Facebook
groups (traffic → article → AdSense). Served (in the next phase) at
**kaumzuglauben.getemoji.site**. WordPress on Docker (Coolify), fully set up on first
start — no wp-admin clicks needed. Cloned from the soap-gold repo (the germ/dales
self-seeding pattern, Style A of the plgin new-site playbook) and rebranded: same
self-seeding engine, fact pillars instead of heritage pillars.

## What's inside
- `wp-content/themes/viral-reader` — parent theme (vendored, v1.9.37, from plgin `main`)
- `wp-content/themes/kaumzuglauben` — brand child theme (v1.0.0): Anton display
  headlines + Literata body (self-hosted), BRAND.md tokens (ink #14161A, paper
  #FFF9EE, shock red #D92B2B, amber #F5B301), category-coloured pillars,
  end-of-article share + "next fact" flow, sticky next-article bar, dark mode
- `wp-content/plugins/automation-hamri` — publishing/SEO/ads engine (vendored, build-v9
  9.48.0 from plgin `main` — the released version; 9.48.1 exists only on the unmerged
  BL-010 branch and was deliberately NOT vendored)
- `wp-content/mu-plugins/kz-page-cache.php` — tiny full-page cache (per URL +
  phone/desktop key, 30 min TTL, purge on publish; logged-in/commenters bypass).
  Header `X-KZ-Cache: hit` on hits.
- `content/site-profile.json` — brand identity (name/tagline/email, writer, assets,
  locales, slugs, categories). The seed reads it for brand/categories; `seed/seed.php`
  holds the fallbacks.
- `content/images/` — committed raster brand assets (icon, logos, OG card, hero).
  Never hotlinked.
- `data/bundles/*.zip` — article bundles (posts.json + images) imported on first start;
  empty at launch until the first content batch lands.
- `seed/seed.php` — brand, de_DE locale (Europe/Berlin), 5 fact categories, 7 German
  trust pages (Über uns, Kontakt, Impressum, Datenschutz, Nutzungsbedingungen,
  Redaktionsrichtlinien, Cookie-Richtlinie), menus, stage-1 ads.txt, bundle import
  (idempotent, resumable). `KZ_SEED_VERSION` 1.
- `docker/site-init.sh` — waits for DB, syncs theme/plugin, installs WP (de_DE) once,
  runs the seed.

## Coolify (next phase — owner approvals)
Docker Compose build pack, compose file `docker-compose.yml` ONLY, domain on the
`wordpress` service. Env vars:
- `SERVICE_FQDN_WORDPRESS_80` (the domain), `SERVICE_USER_MYSQL`,
  `SERVICE_PASSWORD_MYSQL`, `SERVICE_PASSWORD_MYSQLROOT`, `SERVICE_PASSWORD_WPADMIN`
  — generated by Coolify
- `SITE_URL` (default https://kaumzuglauben.getemoji.site), `SITE_EMAIL`, `WP_ADMIN_EMAIL`
- `ADSENSE_CLIENT` / `ADSENSE_PUB_ID` — default ca-pub-6869205417923902 /
  pub-6869205417923902 (getemoji.site family publisher); `ADSENSE_ENABLE=0` at launch
  (stage 1: ads.txt served, no ads — the domain is already approved at family level)
- `GA_ENABLE=0`, `HISTATS_ID` unset/off — analytics off until the owner creates the
  properties
- Google Site Kit — installed/activated by site-init.sh from wordpress.org; owner
  connects Analytics/AdSense in wp-admin. The theme blocks Site Kit's duplicate
  AdSense snippet.

Admin login: user `editor` (WP_ADMIN_USER), password = Coolify's
`SERVICE_PASSWORD_WPADMIN`.

## Local QA
```
copy .env.example .env   (fill in fresh random passwords + salts — never a sibling's .env)
docker compose -f docker-compose.yml -f docker-compose.local.yml up -d --build
# http://localhost:8100 — WP_ENVIRONMENT_TYPE=local applies only in this override
docker compose -f docker-compose.yml -f docker-compose.local.yml down   (volumes kept)
```

## Editorial rules (from BRAND.md)
Staunen, aber wahr — every shock backed by a source. Every fact is checked against
reliable sources before publication (reference works, official records, scientific
publications, reputable reporting); single-source claims are labelled; myths and
rumours are labelled as such; never fabricate numbers, quotes, records or events.
All imagery is our own created content — no stock photos, no lifted images.
